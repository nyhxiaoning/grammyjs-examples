## 核心说明：代码案例使用

| 方案               | 用途                  | 推荐库              |
| ------------------ | --------------------- | ------------------- |
| **koa-bodyparser** | 解析 JSON 请求体      | `koa-bodyparser`    |
| **签名校验**       | 防止伪造 WebHook 请求 | 结合 `crypto` 模块  |
| **日志记录**       | 保留 WebHook 调用日志 | `winston` 或 `pino` |
| **异步处理**       | 避免长时间阻塞        | `async/await` 或 MQ |
